阿遥 · 旅行决策专家

一个帮你翻了几千篇笔记、且最懂你品味的决策搭子

01 — Positioning
功能定位

懂你品味的垂类AI专家，主动追问，辅助你做决定。

02 — Scenarios
适用场景

高壁垒决策场景，如旅行、装修、数码、母婴、留学。

03 — Value
业务价值

降低决策门槛，缩短「种草 → 下单」链路，把内容资产变成转化闭环。

用户痛点 / 需求
决策本质是信息过载 + 个体差异的双重难题
决策痛点

信息分散、内容冗余、时效性不确定，用户需要耗费大量精力筛选笔记才能得出结论。

核心需求

不是「更多信息」，而是一个懂我、能直接帮我做决定的人。

功能价值
AI 决策专家的核心能力
主动式专家规划
主动追问缺口信息（偏好、风格、预算等），像真正的领域达人一样先了解你再给建议，且不重复已知信息。生成的方案包含视觉化笔记卡片、对比清单及避雷指南。
实时社区洞察
回答基于近期真实反馈，捕捉社区最新动态（如"某景区近期施工"、"某电器型号近期集体翻车"）。能识别即时风向，在坑点出现时及时预警。
有立场的建议
面对决策难题给出倾向性推荐，并附理由与笔记来源，拒绝无效回答。支持全过程动态辅助，如在执行计划过程中根据突发情况实时调整建议。
记忆型陪伴
每次对话都沉淀进你的画像，越用越懂你。这些对话不是消耗，而是一份持续增值的「专属决策档案」，跨场景可复用。
商业落地
从决策到履约的完整闭环
赋能本地生活
推荐行程具体到 POI 点位（如具体的咖啡厅、餐厅、买手店），在输出攻略的同时直接挂载门店卡片，通过「决策 → 引流 → 到店」路径深度赋能本地生活业务。
决策即服务
在用户明确意向后，自然承接产品购买、预订、团购及装备购买等服务，实现一键下单的履约闭环。
生态赋能
在提供建议的同时，精准引流至底层相关的博主笔记与商家内容，在促成交易的同时维护创作者生态。

01
垂类专家模型
Continued Pretrain · SFT · DPO
在通用大模型基座上喂入海量旅行笔记做继续预训练，再用达人级对话做 SFT/DPO，把「会追问、会避坑、有立场」直接写进模型权重，而非靠 Prompt 模拟。
02
个性化画像系统
长期画像 + 实时画像
长期画像由收藏 / 点赞 / 搜索行为 embedding 沉淀，实时画像在对话中持续抽取偏好。当用户当下表达与画像冲突时，主动触发避坑提醒。
03
实时社区共识引擎
多模态 RAG · 时间新鲜度加权
笔记多模态向量化后多路召回与重排，按时效性加权，将零散笔记聚合成「社区共识」（推荐 / 避雷的票数与理由），作为每个回答的事实依据。
04
多步 Agent 与结构化输出
对话状态机 · Function Call
对话状态机串联追问 → 检索 → 聚合 → 行程 → POI 挂载 → 导出；LLM 走结构化协议输出，前端按 Schema 渲染笔记卡、对比卡、行程与门店卡。

与 AI 搜索的核心差异
找信息 vs 做决策

点点解决的是「找信息」的问题，阿遥解决的是「做决策」的问题。
决策需要了解你是谁——阿遥调用你的偏好、收藏与互动行为，让每一个回答都是为你定制的唯一解，而非标准答案。
